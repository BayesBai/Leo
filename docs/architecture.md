# 销售员任务到独立渠道交付

React＋Express 单机工作台，凭证只留后端。完整协议从[接口交接固定入口](api/README.md)进入，生图凭证独立于文本凭证；外部设计接入已搁置。

## 执行链路

填写需求 → 后台检索同型号事实与原图 → 各渠道并行策划 → 合并大纲并人工保存/确认 → 各渠道独立写作、规则检查、模型审稿、必要的一次正文返修与复审 → 独立渠道交付。固定标题、段落结构、引用和原图不能由写作或返修模型改写。固定结构问题返回大纲，来源问题重新取证，只有可定位的正文问题进入定向返修。

每个渠道建立ChannelDelivery，只有它自己的阻断问题影响它的复制和正式下载。RunResult仍只表示完整稿件集，部分成功结果不冒充完整RunResult。旧HTTP/SSE与完整稿接口保持兼容；新工作台使用持久Job接口并按渠道展示错误和交付。

| 渠道 | 视觉链路 |
| --- | --- |
| 小红书 | 结构化设计简报→可复用AI背景→真实产品图与精确中文HTML/CSS分层→Chromium；独立封面及分组内页，共3–6页1080×1440 PNG和制作源 |
| 公众号 | 微信兼容内联HTML正文＋1200×510封面；本机排版，正文保持可复制文本，附配图与制作源 |
| 朋友圈 | 独立短文案＋1–3张原图，不制作强制文字拼图，不调用生图 |
| 门店海报 | 结构化设计简报→整图API生成原生1024×1536图像→文字/产品/事实三项人工核对→正式PNG与来源ZIP；无发布文案 |

公众号与小红书可共享一份有效主视觉。共享阶段使用单飞和持久失败检查点，普通重排不重发生图；显式重新生成才创建新一轮。文字与真实产品图保持本机独立层，审核和来源不印入成品。海报走独立整图API；当前不传参考图输入，因此生成图可能写错文字或画错机型，不能作为事实证据。干净预览无正式下载句柄，只有精确绑定bundleId、原始preview artifactId和SHA-256的三项人工核对成功后，才生成正式新句柄。原预览句柄始终不能直接下载，确认不延长期限。

四渠道各自交付。公众号/小红书左发布正文右排版图片，朋友圈单区文案加原图，海报单区一张图。needs_attention表示可交付且有具体发布提醒，来源警告不等待用户点击确认，也不能通过确认大纲抹除；海报人工核对是独立的图片发布门禁。

公众号与小红书默认HTML制作，不接秀米。网站已移除Canva授权、编辑、同步、品牌状态与旧入口。旧外部设计阶段只读保留，所有相关路由和重试统一410 EXTERNAL_DESIGN_PAUSED，零外呼；旧排队任务不自动转换成新模式。规则演示或未配置背景生图时可用本地设计背景；海报整图则需要模型创作和生图配置。

这两个渠道可为有效已审核图文追加20秒无声视频：已审核事实→视频短稿→独立短稿审稿→必要的一次修订与复审→确定性分镜→HTML/CSS＋暂停GSAP时间线逐帧seek→Chromium600帧→FFmpeg背压编码→ffprobe验证→独立videoBundle。固定1080×1920、30fps、H.264/yuv420p。正常2个文本模型节点、修订时最多4个；不调用生图或视频模型，原文章保持不变。失败或取消不撤销图文；仅编码失败续跑复用短稿审核，不重发模型。旧长文直转的VIDEO_COPY_TOO_LONG任务另建新版视频Job，不重试旧算法。

## 调度、恢复与费用边界

默认最多4个文本HTTP请求、2个活跃创作任务、2个本地排版任务，图像请求另限并发1。文本默认180秒、上限300秒；生图上限300秒。明确429有限退避，格式纠正和限流共用每节点两次HTTP预算。524/504、断流、网络错误及其他未知结果暂停，由用户主动重试；已知账号池耗尽立即停止。

静态HTML与视频共用两个Chromium页面槽；视频并发1，仅占一个页面槽，单次本地制作上限10分钟。取消回收对应context、FFmpeg进程与临时文件。视频是独立幂等Job，重启可恢复本地制作，续跑不重新请求正文、审稿或背景；原付费步骤仍按不确定结果保护处理。

付费请求在派发前持久登记，输出与检查点成功落盘后才确认。重启保留成功阶段；没有可靠落盘结果的已派发步骤不自动重发。旧外部设计派发记录仍保留，不因搁置状态清除未知付费结果。文本与生图凭证独立，配置新生图Key不使朋友圈或文本检查点失效。

大纲及任务输入绑定版本与来源。资料变化、证据过期或大纲冲突在真实派发和排版/发布前再次校验。排队期间不能悄悄切换文本模型/Key。

## 数据和门禁

`.local-state/`保存原子JSON、受限权限的令牌和临时视觉文件，`.cache/`保存渲染资源，均不进入Git或Docker构建。历史七天，图片与成品资源三十分钟；读取、缓存命中、有效旧稿重排不延长原期限。损坏记录保留并报错，过期孤儿PPTX/视觉文件会清理。

视频绑定提交时的静态交付指纹，到期时间不超过所复用图文与背景的原期限；MP4预览支持单段HTTP Range。直接MP4/Range/下载均先检查持久渠道门禁，附件丢失不影响对仍存在视频的撤销。制作源ZIP包含页面、设计/分镜配置、素材、字体和许可证，可独立恢复HTML设计。

生成视觉是CreativeAsset，保存模型、Prompt/Skill版本、素材关联与SHA-256，不能进入真实产品证据集合或替代同型号原图。HTML背景不绘制产品或关键中文；整图海报包含模型生成的产品和文字，必须显示对应原图、必需文案与事实条件供人工核对。新图替换会重置核对状态，旧图片不能借新确认绕过门禁。

未实现社交账号自动发布、微信素材库上传、印刷PDF、多租户或远程任务托管。ima真实验收与文本、生图分别记录；配置存在或HTTP200不等于完整验收通过。
