## 每次维护的内容

```text
docs/api/
  README.md                         固定入口与历次索引
  versions/
    YYYY-MM-DD-HHmmss/
      README.md                     本次任务、变更、兼容性与验证
      frontend-handoff.md           完整交接说明
      api-examples.http             请求样例
      fixtures/frontend.mock.json   明确标识的纯模拟数据
      shared/types.ts               响应与共享类型快照
      server/schemas.ts             输入约束快照
      src/App.tsx                   说明所引用的前端实现快照
      manifest.json                 文件及核对源文件的 SHA-256
```

接口有变更时，在新目录中更新正文、类型、请求和模拟数据，并说明前端如何适配；接口无变更时仍新增版本，记录核对范围。未执行的验证不记作通过。

原始交接说明仍保存在 `docs/frontend-handoff.md`，原请求样例和模拟数据也保持原样；后续请以本页的最新版本入口为准。文档归档与代码运行版本分别记录，目录时间不表示 API 路径增加了版本前缀。

维护约定见项目根目录的 [AGENTS.md](../../AGENTS.md)。版本文件只包含可交接的代码与模拟数据，不包含环境凭证和原始知识库。
