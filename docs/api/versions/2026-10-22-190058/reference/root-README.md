# Virgo · 华为 PC 营销内容工作台

面向销售员的「AI+华为 PC 营销软文智能体」参赛 Demo。先理解客户与场景、共创并确认大纲，再生成有产品依据的正文与四渠道视觉成品。独立参赛作品，非华为官方应用。

前后端协作请从 [接口交接版本索引](../../../README.md) 进入最新协议。每次任务新增完整归档，旧版本保留。整体流程与模块见 [架构说明](../../../../architecture.md)。

当前执行步骤见 [前后端协作与本地联调](../../../../frontend-collaboration.md)，提交使用 [PR 模板](../../../../../.github/PULL_REQUEST_TEMPLATE.md)。当前前后端集成进度在 `frontend/workbench` 分支，包含后台队列、分渠道生成与排版、七天历史恢复及 Virgo 界面；协议与本轮检查结果以固定接口入口的最新版本为准。建议团队通过 PR 汇入 `main`。云服务器与共享环境后续另行讨论。

参赛说明材料见 [项目说明书（PDF 与 TeX 源码）](../../../../project-manual/README.md)，其中保留文档基线、实际案例来源和验证范围。

## 启动

需要 Node.js 22.12 或更新版本：

```powershell
npm ci
npm run setup:render
npm run build
npm start
```

setup:render 将官方 Chromium 下载至被忽略的 .cache/ms-playwright/，已有下载可复用。中文静态字体与许可已随代码提供，不需要 Python。Windows 可双击 start-demo.cmd。开发模式使用 npm run dev；默认地址 http://127.0.0.1:3000，以终端打印地址为准。预览地址以当次终端输出为准。

本地演示无需密钥，但需要获授权的产品资料。新克隆不含原始知识库或 .env.local；无资料时只展示公开型号目录，不伪造事实或拿 Mock 数据代替真实检索。前端布局可使用交接版本内明确标识的模拟夹具。

### 本地开发与纯模拟前端联调

运行 `npm ci`、`npm run dev` 后打开终端打印的地址（默认 `http://127.0.0.1:3000`）。开发模式由 Express 内嵌 Vite，前端和 `/api` 同源。只有另开独立 Vite 时才需按协作说明配置保留 Host 的 `/api` 代理。

在地址后加 `?mock=ok` 可进入明确标识的纯模拟流程，例如 `http://127.0.0.1:3000/?mock=ok`。它由统一前端 transport 模拟 JSON、SSE、配置验证与资源请求，不访问真实 API、模型或 ima，无需密钥和知识库。可改用 `blocked`、`needs_input`、`error`、`empty`、`slow`、`expired`、`conflict`、`disconnected`、`insufficient-images` 检查异常状态；删除参数并刷新恢复真实接口。Mock 仅证明界面流程，不等同规则演示或真实接入。

## Virgo 网站与设计交接

已将确认的花园封面与五色工作台接入现有 React 项目，包含手机布局、方案版本确认、来源与七天记录、审核阻断、真实成品预览和下载。设计与实现从 [Virgo 交接入口](../../../../design/virgo/README.md) 进入，[本轮验证](../../../../design/virgo/implementation/2026-10-22-web/verification.md)分开记录 Mock、实际 HTTP 演示与模型／ima。

入口先展示封面；开发时可使用 `#workbench` 直达工作台。界面使用本地字体和分层素材，网站运行不依赖 Figma。接入配置在右上设置中；手机通过菜单打开，首页独立可见。默认端口与知识来源仍由现有后端配置决定。

## 销售员的使用流程

1. 填写任务：选择具体产品、业务场景和目标客户，选择公众号、小红书、门店朋友圈或门店海报，每次支持 1–4 个不同渠道。营销目标有默认值，补充要求按需展开；切换场景不静默覆盖客户。接入设置为独立入口，已有配置可直接使用。
2. 确认大纲：策划和 AI 修改进入后台队列，可继续查看历史或新建任务。先看标题、内容切入和段落摘要，按需展开编辑与配图；保存后产生新版本，人工确认当前版本。
3. 加入生成队列：自动按渠道串接正文、独立审稿、必要的一次返修及排版。较快渠道先提供带标记预览，全部渠道终审后统一开放正式复制、下载与 ZIP；审核阻断仍禁止整组导出。

任务中心支持查看、单独停止和失败步骤续跑。切换渠道或刷新页面只改变查看内容，后端运行时任务继续执行。默认最多四个模型 HTTP 请求、两个活跃创作任务和两个排版任务；成功阶段写入本地检查点。524、504、超时、断流或网络错误不会自动重发，主动重试可能再次产生消耗；明确的429限流可有限退避。服务重启不重发结果不确定的付费步骤，用户需主动恢复。运行与排队任务绑定提交时的配置，完成或停止清理前不能切换模型凭证。

同一大纲被旧流式生成或后台队列占用时，保存、确认、AI 修改和失败任务重试返回 409；取消后须等待实际清理结束。任务中心显示完成或停止后，再主动执行下一步，避免并发生成旧版本或重复消耗。

大纲标题、段落 ID/顺序/标题、引用与配图由服务端固定，模型仅填正文；返修也不能覆盖已确认结构。大纲确认只表示写作方向确定，正文审核仍独立进行。被审核阻断的结果只提供带标记预览，正式下载与复制入口禁用。

## 模式与接入

| 模式 | 文案创作 | 产品资料 |
| --- | --- | --- |
| 本地演示 | 明确标识的规则大纲、规则正文与初检 | 本地 P1 原文及真实图片 |
| 模型 + 本地资料 | 模型大纲、写作、独立审稿，必要时一次修订 | 本地证据，有来源待确认标记 |
| 模型 + ima | 同上 | 账号实际有权读取的指定共享库 |

页面配置只保存在本地后端进程内存，空白字段保留原值；不会回显密钥，不写入浏览器存储、归档或 .env.local，重启后恢复环境配置。本 Demo 是单操作者本机工作台。模型域名只能使用新网关或服务启动时配置的域名；新增域名请由后端修改环境配置并重启。

HTTP 仅接受 localhost、127.0.0.1、[::1] 或服务端明确配置的 HOST。写入请求的 Origin 必须与请求的协议、Host 和端口一致；命令行可不发送 Origin。独立前端请通过 Vite 代理访问相对 /api 路径，并保留 Host（changeOrigin: false），不能直接跨端口写入。取消任务后，后端完成实际清理才释放配置锁；此时修改配置仍可能短暂返回409。

持久配置复制 .env.example 为 .env.local，在本机填写：

```dotenv
LLM_BASE_URL=https://relay.nccnxta.cn/v1
LLM_MODEL=gpt-6.1-sol
LLM_API_KEY=
IMA_OPENAPI_CLIENTID=
IMA_OPENAPI_APIKEY=
IMA_KB_NAME=任德耀新建华为PC知识库
```

不要把实际密钥发到聊天或提交仓库。所有大纲、AI 修改、写作、返修和独立审稿统一使用 OpenAI 兼容 Chat Completions：POST https://relay.nccnxta.cn/v1/chat/completions，Authorization: Bearer 鉴权，模型 gpt-6.1-sol。模型名称为网关路由标识；实际可用性以真实生成结果为准。Base URL 可填根地址或 /v1，不接受完整接口路径。页面更换网关仍须同时提供该网关的新密钥，不会自动把旧密钥发送至新域名。本轮已按操作者明确授权，在本机环境配置中迁移到新网关并继续使用当前 Key；未放宽页面跨域凭证保护。

后端仅累计正文文本，使用 Zod 检查 JSON；格式错误允许一次纠正重试，429/502/503/504 允许一次有限重试。若网关明确报告模型可用账号池耗尽，则显示具体原因并停止本次调用，不立即重复请求；需由网关服务商恢复该模型线路。默认每次调用超时 180 秒（LLM_TIMEOUT_MS 可调，最高 300 秒）。不发送原 Messages 协议的 thinking 参数，也不自动切回旧网关或其他模型。

ima 需加入对应共享库，保留 ima-skill/ima_api.cjs，只读搜索与获取原文和图片；不上传、更改知识库。支持 IMA_CLIENT_ID / IMA_API_KEY 别名和官方配置文件。默认本地资料目录为 华为PC知识库/华为PC全板块深度知识库_v7，可由 LOCAL_KB_ROOT 指定。仅读取当前型号的产品参数与图片，不把历史软文、培训资料或竞品内容当作新事实。

## 四渠道成品

| 渠道 | 已实现输出 | 运行时 |
| --- | --- | --- |
| 公众号 | 内联样式文章 HTML、1200×900 封面 PNG、富文本复制、ZIP | 文颜 Core + Satori / Sharp |
| 小红书 | 大字收藏封面、编号清单内页、深色互动收尾共 3–6 张 1080×1440 PNG | MIT 卡片框架派生模板 + Playwright |
| 门店朋友圈 | 一张社交拼图 PNG，合成 1–3 张原图；1080×1080 方形或 1080×1440 竖形，附独立文案 | Satori + Sharp |
| 门店海报 | 一张 1080×1920 PNG，最多三个卖点 | Satori + Sharp |

策划与写作分别使用渠道专属要求：公众号是问题分析和选择建议，小红书是行动清单，朋友圈是单看点私域沟通，海报是短标题与卖点主视觉。公众号封面、朋友圈图卡和海报使用不同构图树；共用字体与光栅化工具。审核比较标题、开场、段落标题与CTA的重合度，过于相近时保留渠道警告并进入既有一次修订；这个启发式检查不能代替人工判断。

生成后的文字不因排版被重写或截断；会尝试缩放，仍放不下则明确报错。图片从当前证据包解析，保持型号和原图比例；素材不足时拒绝出图，不复制图片充数。成品保留来源/审核标记，ZIP 附文案及可读的来源与审核说明，不含原始知识库全文、签名 URL、凭证或服务器路径。

公众号图片目前是嵌入式预览，尚未上传到微信素材库；粘贴到公众号后需上传或替换图片并复查。未实现自动发布、账号登录、印刷 PDF 或在线图层编辑器。许可、固定版本与已知依赖审计项见 [第三方声明](../../../../../server/render/THIRD_PARTY_NOTICES.md)。

## 验证与示例

```powershell
npm run check
npm test
npm run build
npm run demo:render
```

demo:render 使用获授权的本地 MateBook 14 鸿蒙版资料，逐渠道完成大纲、确认、正文审核与出图，真实文件保存在 output/four-channel-demo/；该目录因含产品摘录被 Git 忽略。没有本地资料时命令会明确失败。朋友圈现为包含多张原图的一张拼图；小红书页数取决于段落数。

同任务四渠道验收：先在 9755 启动实例，再运行 `npx tsx scripts/compare-channels.ts`（规则演示），或在已授权模型目的地和产品摘录发送范围后运行 `npx tsx scripts/compare-channels.ts --live`（会调用真实模型）。同一 Brief、同一确认大纲、同一次正文结果顺序渲染四个渠道，保存文章、PNG、文案、允许导出的 ZIP、审核与尺寸记录到 `output/channel-comparison-*/`，并生成可独立打开的 `comparison.html`、四图总览 PNG。预览页复制到 `dist/four-channel-comparison.html`，下次 build 会清除；资料和运行产物不进入 Git 或接口归档。

仅修改规则后复核原稿，可运行 `npx tsx scripts/reaudit-comparison.ts <原comparison目录>`。该工具核对所用事实及条件没有变化，保持文案字节内容不变，沿用该稿已有的独立模型审稿，再用当前规则与生产渲染器重算并输出；不重新调用模型，报告会注明这一点。有硬错误则拒绝生成可导出对照。

默认 npm test 使用独立临时模拟知识库和假凭证，阻止外部网络，不读取真实 .env.local；缺图在调用大纲模型前返回 422。审核问题按正文返修、返回大纲、重新取证或人工核实处理，固定结构不进行无效自动返修。

测试覆盖七天历史与跨进程重启、旧接口、图片型号绑定、模型与 ima 模拟合约，以及大纲版本/确认/取消、真实中文 PNG、溢出拒绝、HTTP 状态、受控渲染输入、审核阻断下载和 ZIP 来源说明。本机另用浏览器走通大纲手动编辑、保存 v2、确认、双渠道正文与实际成品预览。

真实接入与模拟测试分开记录。旧网关、gemini-4-argon 与 DeepSeek 的历史联调不能证明当前 gpt-6.1-sol 可用；本轮新网关真实结果以接口固定入口的最新归档为准。历史 ima 联调曾遇到每日读取额度限制，未作为本轮真实 ima 通过记录。审核结论、工具运行与平台发布分别验收。

## 运行边界

大纲和成稿保存于被忽略的 .local-state/（可用 AGENT_STATE_DIR 指定）。大纲成功保存后保留七天，成稿生成完成后保留七天，读取不续期；重启和页面刷新可恢复已保存内容。每份成稿保留当时确认的大纲快照，旧稿不套用后续版本。浏览器只保存当前记录的种类和 ID。未完成的模型请求不会在重启后自动重发。

ima 证据和临时原图、成品 HTML/PNG/ZIP 仍按原始时间在 30 分钟后失效；重启不重置时效。成品保存在 .cache/render/，最多保留 20 组。来源变化或证据失效时，历史仍可读，新创作/排版须重新取证；不会延长知识授权。正文生成最多两个并行任务，渲染最多两个；渲染超时 90 秒。

默认只监听 127.0.0.1，无多用户鉴权或公开部署配置；本地历史使用原子 JSON 文件，无需数据库服务。模型失败不切换为规则演示；ima 失败不使用本地图冒充正式素材。原文支持 Markdown、文本、HTML 与有权限笔记；PDF / Office 原文当前适配器明确提示不支持。

本机请求来源校验、错误脱敏、模型响应读取上限、渲染文字转义、受控图片来源和前端 SSE/成品绑定有专门回归测试。依赖审计仍有五项中危报告，集中在未调用的 front-matter 依赖链，详见第三方声明；不代表完成公开部署安全验收。

后端早期基线来自 `backend/api-handoff` 的 `5008332`；之后的前后端集成与接口归档一并维护在 `frontend/workbench`，实际提交以 Git 记录为准。队友拉取完整代码后按上述步骤本地启动，密钥、知识库与运行产物仍需在本机配置。
