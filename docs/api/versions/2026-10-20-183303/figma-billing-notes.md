# Figma MCP 额度与订阅咨询

核验日期：2026-10-20。仅查阅官方公开资料，没有继续调用 Figma MCP、购买套餐或充值；不推定实际账户剩余次数或重置日。

- Starter 或 View/Collab 席位每月最多 20 次 MCP 调用；Professional Full/Dev 每天最多 200 次、每分钟 10 次；经验证的 Education Full/Dev 同 Professional。限制主要针对读取工具，部分写入工具及 whoami 豁免，不能把所有 Figma 操作都按同一计数理解。具体工具与后续调整以[官方额度说明](https://developers.figma.com/docs/figma-mcp-server/rate-limits-access/)为准。
- MCP 次数与 AI credits 分开：多数 MCP 工具不消耗 AI credits；生图、向 Make 发送提示等消耗 AI credits，且不计入 MCP 读取额度。购买额外 AI credits 不等于增加 MCP 读取配额。[官方说明](https://developers.figma.com/docs/figma-mcp-server/rate-limits-access/)
- Starter 免费档当前列出每日 150 AI credits、每月最多 500；这与 MCP 的每月 20 次是两种额度。未核实价格对应的计费周期，本咨询不列具体订阅价格。[官方价格页](https://www.figma.com/pricing/)
- 符合资格并通过验证可建立免费教育团队；不保证当前用户符合资格或认证必过。[Education 帮助](https://help.figma.com/hc/en-us/articles/360041061214-Figma-for-Education) · [教育计划](https://www.figma.com/education/)

当前比赛可先免费评审现稿，并用已有设计与资产实施网站。需要频繁由助手直接修改 Figma 时再考虑 Professional Full；Full 适合编辑设计，Dev 侧重开发交接。此次没有进行购买，也没有改变既有设计验收状态。
