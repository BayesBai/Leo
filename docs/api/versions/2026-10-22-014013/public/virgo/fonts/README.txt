Virgo self-hosted fonts

Pinyon Script Regular: Google Fonts / The Pinyon Project Authors, SIL OFL 1.1.
Noto Sans SC: Google Fonts / Adobe, SIL OFL 1.1. Weights 400, 500, 600.

Downloaded from the official Google Fonts CSS API and fonts.gstatic.com.
The unsuffixed WOFF2 files are retained complete originals compressed without outline changes.

Runtime weights 400 and 500 use a GB2312 + ASCII + punctuation common fragment and disjoint remaining-character fragments (at most 2048 mapped characters each). fonts.css selects these with unicode-range, keeping the same family and weight. FontTools retains all original mapped characters, Unicode variation sequences, layout features and character metrics. The union is checked against each complete original. No outline edits or lossy compression are used. Weight 600 and Pinyon Script remain complete files.
