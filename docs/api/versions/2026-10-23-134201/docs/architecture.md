# 销售员任务到独立渠道交付

React＋Express 单机工作台，凭证只留后端。完整协议从[接口交接固定入口](api/README.md)进入，配置步骤见[生图与Canva接入指南](setup/visual-integrations.md)。

## 执行链路

填写需求 → 后台检索同型号事实与原图 → 各渠道并行策划 → 合并大纲并人工保存/确认 → 各渠道独立写作、规则检查、模型审稿、必要的一次正文返修与复审 → 独立渠道交付。固定标题、段落结构、引用和原图不能由写作或返修模型改写。固定结构问题返回大纲，来源问题重新取证，只有可定位的正文问题进入定向返修。

每个渠道建立ChannelDelivery，只有它自己的阻断问题影响它的复制和正式下载。RunResult仍只表示完整稿件集，部分成功结果不冒充完整RunResult。旧HTTP/SSE与完整稿接口保持兼容；新工作台使用持久Job接口并按渠道展示错误和交付。

| 渠道 | 视觉链路 |
| --- | --- |
| 小红书 | 结构化设计简报→可复用AI背景→真实产品图与精确中文HTML/CSS分层→Chromium；独立封面及分组内页，共3–6页1080×1440 PNG和制作源 |
| 公众号 | 微信兼容内联HTML正文＋1200×510封面；本机排版，正文保持可复制文本，附配图与制作源，不依赖Canva |
| 朋友圈 | 独立短文案＋1–3张原图，不制作强制文字拼图，不调用生图 |
| 门店海报 | 设计简报→独立AI背景→真实产品与中文独立层→Canva编辑/导出，1080×1920 |

默认四渠道共享一份主视觉并另生成一份海报背景。共享阶段使用单飞和同轮失败检查点；即使另一个渠道稍后到达，也不能在同一轮自动重发失败生图。普通重排复用成功素材，额外生成必须显式触发。旧稿可本地重新排版清除审核标签，不调用文案模型。审核记录与来源是独立附件，不印入图片或正文。

公众号与小红书默认HTML制作，不接秀米；历史Canva工程和排队任务保留原模式，用户主动重新排版后采用HTML。规则演示或未配置生图时使用本地设计背景。新背景成功素材跨任务复用；持久派发标记阻止未知结果被其他任务绕过重发。

这两个渠道可为有效已审核图文追加20秒无声视频：完整审核短句与适用条件→确定性分镜→HTML/CSS＋暂停GSAP时间线逐帧seek→Chromium的600帧→FFmpeg背压编码→ffprobe验证→独立videoBundle。固定1080×1920、30fps、H.264/yuv420p，文案无法清楚呈现时拒绝制作，不另调模型。视频失败或取消不撤销原图文；版本变化时拒绝发布旧视频。

## 调度、恢复与费用边界

默认最多4个文本HTTP请求、2个活跃创作任务、2个本地排版任务，图像请求另限并发1。文本默认180秒、上限300秒；生图上限300秒。明确429有限退避，格式纠正和限流共用每节点两次HTTP预算。524/504、断流、网络错误及其他未知结果暂停，由用户主动重试；已知账号池耗尽立即停止。

静态HTML与视频共用两个Chromium页面槽；视频并发1，仅占一个页面槽，单次本地制作上限10分钟。取消回收对应context、FFmpeg进程与临时文件。视频是独立幂等Job，重启可恢复本地制作，续跑不重新请求正文、审稿或背景；原付费步骤仍按不确定结果保护处理。

付费请求在派发前持久登记，输出与检查点成功落盘后才确认。重启保留成功阶段；没有可靠落盘结果的已派发步骤不自动重发。Canva导入保存原远程job ID，查询可继续；不确定的编辑/导出先同步核对原设计。文本与生图凭证独立，配置新生图Key不使朋友圈或文本检查点失效。

大纲及任务输入绑定版本与来源。资料变化、证据过期或大纲冲突在真实派发和排版/发布前再次校验。排队期间不能悄悄切换文本模型/Key；Canva操作绑定账号授权，重新授权不能复用旧账号的操作检查点。

## 数据和门禁

`.local-state/`保存原子JSON、受限权限的令牌和临时视觉文件，`.cache/`保存渲染资源，均不进入Git或Docker构建。历史七天，图片与成品资源三十分钟；读取、缓存命中、有效旧稿重排或Canva同步不延长原期限。损坏记录保留并报错，过期孤儿PPTX/视觉文件会清理。

视频绑定提交时的静态交付指纹，到期时间不超过所复用图文与背景的原期限；MP4预览支持单段HTTP Range。直接MP4/Range/下载均先检查持久渠道门禁，附件丢失不影响对仍存在视频的撤销。制作源ZIP包含页面、设计/分镜配置、素材、字体和许可证，可独立恢复HTML设计。

生成背景是CreativeAsset，保存模型、Prompt/Skill版本、真实素材关联与SHA-256，不能进入真实产品证据集合，也不能代替至少一张同型号原图。生图不绘制产品机身或关键中文，产品图与文字保持独立层。

Canva同步按文字和产品图片素材标识比较，纯布局变化复用原审稿，内容变化撤销该渠道资格。旧下载句柄和不带deliveryId的兼容排版请求也不能绕过撤销。Canva签名导出URL立即回收到本机，不当作长期成品链接。设计编辑链接保留，远端字体、换行与图层质量需实际授权后的验收。

未实现社交账号自动发布、微信素材库上传、印刷PDF、多租户或远程任务托管。ima真实验收与文本、生图、Canva分别记录；配置存在或HTTP200不等于完整验收通过。
