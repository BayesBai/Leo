## 域名、备案与证书

杭州是中国大陆节点。未备案的其他独立域名不能因为同一服务器已有一个备案域名，就直接对外开通网站。即便能够设置 DNS 记录，也不表示满足备案和接入条件；CNAME 到已备案域名同样不能转移备案资格。

普通域名备案完成后，其子域名通常无需单独 ICP 备案；备案信息仍须有效，且接入商、主体和实际内容应符合要求。若 agonionce.beer 已在阿里云完成备案/接入，优先复用该域名的子域名；若仅在其他接入商备案，先按阿里云要求完成接入。不会因新增子域名就天然要求下线既有个人网站，具体变更流程须在办理前确认。

若现有备案是个人性质，而 Virgo 后续公开提供产品营销或企业相关服务，应先向接入商确认主体和内容范围，不能仅以子域名或小范围使用判断符合备案要求。入口密码也不替代备案要求。

若以后改用中国香港或境外服务器，域名仅解析到这些非中国内地服务器时，一般无需中国大陆 ICP 备案；涉及中国大陆 CDN/边缘节点时另核对对应要求。本轮继续优先规划杭州现有服务器，不新增采购。

未来 DNS 只需为 `virgo` 增加指向目标服务器的记录；保留 `@`、`www` 及其他现有记录。HTTPS 证书必须覆盖 `virgo.agonionce.beer`；仅覆盖根域名的证书不自动覆盖子域名。是否已有通配符证书待盘点；不在本轮申请或变更。

## 拟采用的结构

```text
同一台杭州服务器上的现有 HTTPS 网关
  agonionce.beer / 原有 www 配置 → 个人网站现有服务
  virgo.agonionce.beer           → 入口密码 → Virgo 独立本机端口
                                                 ├─ dist 前端
                                                 ├─ /api、SSE、成品与受控原图
                                                 ├─ 独立状态目录
                                                 └─ 独立渲染资源目录
```

生产 Express 可以同时托管前端和 API，先按同源整站部署规划，无需另建 api 子域名或跨域开放。进程保持单实例，后台状态为原子 JSON 且有单写者锁；不能直接以多个副本共享状态目录。几个使用者将共用工作区、历史和连接配置；入口密码不是独立账号或数据隔离。如需各自独立历史或密钥，另行设计用户体系。

选择 Docker 或 systemd 需等待现有环境盘点。应用只绑定本机可用端口；容器方案仅向本机发布应用端口。公网入口复用现有网关，避免直接暴露后端端口绕过入口密码。

## 2 核 / 2 GiB 的资源安排

不能仅凭使用人数或标称带宽承诺可承载现有完整流程。2 GiB 同时运行个人网站、Node、Chromium 和 FFmpeg 可能不足；本轮没有登录服务器或压测，未测得可用内存、峰值 RSS、OOM、磁盘余量或现有网站负载。

建议先以图文工作流和受邀试用为第一阶段：规划将创作与渲染限制为单任务，避免同时运行两个 Chromium 页面或叠加视频编码。当前代码的部分并发值固定为 2，此项是未来改造计划，本轮没有实施。文本/生图由外部 API 执行，但图文排版与视频帧仍消耗本机 CPU/内存，不能将全部负载视为云端模型消耗。

视频功能先不作为第一阶段开放能力，待同机资源验证后决定开启、扩容内存或将渲染独立运行。任何菜单隐藏均不能代替后端能力限制，实施时需完整设计。无需现在购买更高配置。200 Mbps 的峰值性质和月流量待查；它不消除内存限制。若个人网站健康状态或延迟恶化，应能单独停止 Virgo 并回滚新增站点配置。

## 正式部署前需完成的项目工作

1. 访问边界：全站入口密码，凭证由服务器安全保存；统一保护配置接口、生成接口和读取/下载路径。当前应用没有多用户登录，Host/Origin 校验不能当作身份认证。
2. 反代适配：当前 HOST 同时用于监听与允许主机；0.0.0.0 不会允许任意域名，不应直接把 HOST 改成子域名。规划将监听地址和允许的公共域名分开，并只信任实际本机/容器代理，正确处理 TLS 终止后的协议与 Origin。当前直接套反代可能得到 403。
3. 运行依赖：Node >=22.12，Chromium、中文字体和 Linux 浏览器运行库；视频另需含 libx264 的 ffmpeg 与 ffprobe。当前 Dockerfile 只装 npm 依赖和构建，没有完整安装浏览器/系统库/视频工具，不能视为已具备完整出图环境。
4. 数据：独立持久保存 AGENT_STATE_DIR（默认 .local-state）及 AGENT_RENDER_DIR（默认 .cache/render）；知识库如需使用，通过有授权的只读路径挂载，不放到公开站点目录或文档。镜像替换不能删除状态。Chromium 安装目录不应被空挂载覆盖。
5. SSE/下载：网关关闭 SSE 缓冲/缓存，支持持续连接、15 秒心跳及足够超时；保留 MP4 Range/206/416。成品必须经后端校验，不直接公开缓存文件夹或用 CDN 缓存私有任务接口。
6. 外部连通：后续在目标环境验证文本模型、生图和按需 ima 的出口；本轮不进行真实调用。Canva 已搁置且相关路由返回 410，不作为上线依赖。上一版本记录生图网关 403 尚未通过真实海报验收，部署本身不代表该故障解决。
7. 交付与恢复：保存网关配置备份，独立日志及重启策略；状态和相关素材一致性备份，恢复时保留原到期时间。应用七天历史及约三十分钟临时资源策略仍有效，不能把备份当作延长授权。
