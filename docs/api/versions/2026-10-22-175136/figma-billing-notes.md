# Figma 额度与付费说明（只读咨询）

本轮查询官方说明，没有继续操作设计文件、购买订阅或充值，也没有改应用接口。

- Starter 是免费计划，可手动设计；MCP 工具调用额度与正常编辑、Figma AI 积分分别计算。
- 当前官方 MCP 文档：Starter 及 View/Collab 最多每月20次；Professional Full/Dev 最多每日200次、每分钟10次。部分写入工具豁免，生图与 Make 的 AI 积分操作另算。不能由报错推定账户精确已用次数或重置日期。
- AI 积分用于 Figma 生图、Make 等功能；额外购买 AI 积分不会增加 MCP 调用次数。Starter 当前含150积分/日、最多500积分/月。
- 付费方案按团队席位订阅。需要直接编辑设计应关注 Full；不能只因 Dev 也有较高 MCP 限额就认为其拥有相同设计编辑权限。未承诺具体美元价格，月付/年付与实际结算需查看官网。
- 符合资格并完成验证的学生/教师可申请免费 Education 团队；官方 MCP 文档给予同 Professional Full/Dev 的限额。不保证用户符合资格或认证通过。
- 对本次比赛建议先使用免费计划评审现稿和本地资产；需要频繁通过 MCP 操作时再考虑 Professional Full，不建议为 MCP 限额盲目购买 AI 积分。
