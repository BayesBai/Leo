## 文档基线与当前代码

这是保留原始验证记录的 v1.0 说明书，工程验证基线为 `8574709`，不是后续所有改动的验收报告。文档中的 89 项回归、实际案例与版式属于当时基线；后续同任务四渠道、独立构图和 DeepSeek 接入的行为与最新验证，请以[接口交接固定入口](../api/README.md)及[当前架构](../architecture.md)为准。

本次发布逐字节复制已交付的 PDF、TeX、素材和证据清单，未重新生成案例或调用模型/ima。`source/document-manifest.json` 记录源文件及 PDF 的 SHA-256。源项目 README 中关于仅保存在 `output/`、未自动推送的文字记录初次生成时的状态；本目录现已作为用户授权的仓库交付内容。

案例包含选录的实际营销输出与配图，来源和待确认状态均保留；本地资料示例不能替代赛事指定 ima 共享库验收。未打包原始知识库、赛事手册 PDF 或凭证。正式提交仍需补齐 ima 正式样例、魔搭页面及相应录屏，详见说明书。

## 编辑与编译

进入 `v1.0/source/`，使用带中文宏包和 Fandol 字体的 TeX Live，以 XeLaTeX 编译 `main.tex` 两次；也可执行其中的 `build.ps1`。`main.pdf` 是本机编译产物，仓库内的发布 PDF 为上方固定文件。
