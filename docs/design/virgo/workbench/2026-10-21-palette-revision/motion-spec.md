# Virgo v3 动效与响应式修订

本轮只改变工作台进入方式和工作台视觉。原封面的 1 秒开场、花草轻风、人物与景深范围保留，人物不悬浮。没有制作背景循环视频或实际鼠标跟随。

## 进入工作台

- 原生时间轴节点：`86:31384`，总时长 0.6 秒。
- 全尺寸风景、人物、阴影、前景及原封面界面：0–0.35 秒，透明度 1→0，EASE_OUT。
- 新工作台纸面：0–0.2 秒保持透明，0.2–0.6 秒透明度 0→1，EASE_OUT。
- 风景不改变宽高、位置或圆角；删除旧版收束为花园窗的 WIDTH、HEIGHT、TRANSLATION_X/Y 和 CORNER_RADIUS 轨道。
- 品牌栏通过重叠淡化衔接。终帧使用真实 v3 需求纸面的克隆，尺寸和文字与工作台一致；0.6 秒自动进入实际可交互需求页。
- 入口保持可用；点击进入后不额外插入等待、逐字打字或加载百分比。

原生视频导出宽 768、10fps，抽查 0／0.3／0.6 秒。MP4 编码含末帧停留而为 0.7 秒，设计时长仍为 600ms。

## 工作区与控件

- 页面切换约 180–220ms；按钮 120–180ms；弹层 180–240ms。保留可中断、快速响应的原则。
- 主按钮底色：默认 `#A0AFB6`、悬停 `#9CAAB1`、按压 `#97A5AC`；文字和聚焦轮廓 `#30383B`。
- 选中渠道通过灰绿底、勾选和深色边界表达。审核使用独立语义色、图标和文字。
- 手机保留底部操作区，固定子项与安全区域保持；标题、页签和正文允许纵向自然延展。
- 桌面页头仅有 Virgo 与“接入设置”“首页”，手机有“菜单”“首页”。不留花园窗占位。
- 首页进入完成态／静态封面，不触发首次开场。生成期间禁用导航与设置；停止操作仍保留。

## 减少动态

独立 Page `85:148` 中有完整减少动态流程。无持续摆动、景深或明显位移，页面／浮层转换 ≤100ms。结构读取未发现超过 100ms 的过渡。手机不启用持续背景运动。

Figma 原型定义视觉意图。网页阶段仍需检查 `prefers-reduced-motion`、真实焦点捕获与恢复、快速重复操作、鼠标跟随、触控和性能。本轮没有安装动画库或编写网站动画代码。
