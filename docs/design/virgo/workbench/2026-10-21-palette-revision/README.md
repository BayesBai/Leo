## 本轮修改

- 五色采用 `#A0AFB6` 雾蓝灰、`#B3B69E` 灰绿、`#E6CDC6` 柔粉、`#E5CAB5` 桃杏、`#E6DDD4` 贝壳米白。
- 纸面 `#F7F3EF`；主要文字 `#30383B`；辅助文字 `#4F585C` 仅用在中性浅底。蓝灰和灰绿区域使用主要文字。普通文字 19 组实色组合最低 4.73:1。
- 主按钮为雾蓝灰底配深色字；悬停 `#9CAAB1`、按压 `#97A5AC`、深色聚焦边界。渠道选中增加勾选及深色边界。审核语义色与图标保留。
- 移除全部工作页的花园小图及占位。桌面右上依次为“接入设置”“首页”；手机为“菜单”“首页”。生成期间禁用相关入口。
- 需求标题为“Virgo-你的产品规划搭子”；说明为“选好产品、客户和渠道，明确大方向”；按钮为“生成营销方案”。方案页使用“确认营销方案”“按你的想法调整，确认后生成内容。”；交付页使用“营销内容与成品”。其他功能及模拟内容保留。
- 进入工作台改为 600ms 的全景淡出与纸面显现，不再收束为小窗。首页返回完成态，避免重放开场。
- 保留 1440、1280、390、减少动态流程以及来源、设置、状态和恢复画板。69 个组件变体／独立组件、15 个组件集；旧花园窗组件未复制进 v3。

渠道成品继续使用原有受控排版和颜色，工具色板没有覆盖到成品示意中。封面 8 对画板、293 个节点的视觉属性比较无差异，交互目标仅重绑到新流程。

## 实际验证

- 桌面／手机／减少动态分别检查 151／187／150 个工作页页头：没有花园窗、缺失首页、旧文案或文字横向越界。
- 全部导航和浮层的 1318／1676／1265 条页面目标动作均存在、位于当前新版页；其中浮层动作 347／443／331 条。此数字包含状态示例，不代表人工点击次数。
- 32／56／32 个阻断复制、下载或生成成品控件均禁用且没有动作；生成期间页头禁用规则已统一。保存修改 → 保存 v2 → 确认 v2 → 写作 → 审核 → 等待出图 → 排版 → 交付的目标链已读回。
- 普通文字按 Figma 实际实色及透明度读取，13,172 个节点均达到 4.5:1；646 个禁用文字节点另记豁免。照片背景和原有渠道示意不包含在这项实色计算中。
- 13 张 PNG 导出；独立检查 12 张主要截图并针对修复后的 1280 方案复核。初次指出的证据卡低对比判断在实际颜色读回后撤回；其实际为 `#30383B / #A0AFB6`，5.30:1。
- 600ms 时间轴导出 768×534／10fps 视频并检查 0／0.3／0.6 秒；编码含末帧停留，文件时长 0.7 秒。终帧为新版需求页。减少动态版读取到的过渡均 ≤100ms。

尝试通过内置浏览器打开新版 Figma 原型，30 秒超时、会话重置；完整人工点击和真实键盘焦点检查未完成。结构检查、截图、动画抽帧分别记录，不互相替代。未运行应用测试、构建、真实模型或 ima，未验证实际剪贴板、下载、鼠标跟随、触控与性能。
