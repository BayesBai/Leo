# Virgo 工作台 60% 纸面静帧

桌面主纸面由80%不透明度降为**60%**，保持8px模糊与24%贝壳色背景薄罩。正文、编辑区与输入框仍94%；手机主纸面仍94%，无背景模糊。仅改工作台CSS，封面、背景素材、布局、字体与品牌五色保持。

桌面辅助文字`#353C40`、必要控件边界`#4B575D`、输入占位字`#616D72`。主文字、弹层、审核提示与固定操作保持原有阅读保护。
