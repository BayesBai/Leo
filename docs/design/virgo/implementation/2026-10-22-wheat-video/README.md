## 网页行为

独立背景在工作台外壳挂载，避开带step key的正文。首次600ms封面过渡结束后才加载；真正playing后300ms显现，静帧始终兜底。顶栏暂停/恢复与业务忙碌状态独立，键盘可操作；本页面内保留用户暂停选择，与封面控制互不影响。

步骤、渠道和抽屉切换不重新创建视频；返回首页、页面隐藏暂停并保留时间。仅合格桌面加载视频，失去设备/减少动态资格会释放媒体源。加载或自动播放失败回退静帧，只有用户点恢复才重试。

发现并修复一处真实键盘竞态：后台自动换step的正文聚焦会抢走背景按钮Space键。现在仅在背景按钮已获焦时保留它，其他步骤仍沿用正文聚焦。修复后在后台任务进行中实测Space暂停成功。
