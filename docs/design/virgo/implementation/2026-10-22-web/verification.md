## 动效与素材

1 秒开场、8 秒轻风、2／6／10px 分层景深、暂停、600ms 封面到工作台过渡均实现。实际鼠标位移读回为 1:3:5，人物与阴影同层；暂停与 390 手机三层均为 none。抽帧发现并修复封面底色未退出的问题，最终关键帧和完成态已复核。[动效证据](motion/README.md)记录截图时序与取样限制，不能据此宣称 60fps。

CSS 和 GSAP 的减少动态门禁已检查；没有在系统层切换该偏好。图片转无损 WebP 后减少 33.9%，可见像素和透明度一致。字体保留完整字库、字宽及许可，常用 400／500 分片减少初始字体字节 73.1%；实际流量取决于用字。[素材记录](asset-performance.json)。
