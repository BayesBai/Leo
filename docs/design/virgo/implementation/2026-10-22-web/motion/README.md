# 网站动效与浏览器证据

封面首次进入约 1 秒，按钮和导航始终可操作；前景轻风周期 8 秒。桌面细指针的远景／人物与阴影／近景运动范围为 2／6／10px。返回首页显示完成态，暂停偏好保存在浏览器；手机与系统减少动态均不创建持续动景和景深。

进入工作台使用 600ms 交叉淡化：整个封面（包括底色）0–350ms 线性淡出；纸面在 200–600ms 显现。最初抽帧发现底色没有退出，现已针对这一点修正并复核。减少动态使用封面 80ms、工作台 100ms 淡入。普通按钮 120–160ms，工作页 200ms，抽屉 220ms；支持现代原生 details 插值的浏览器增强折叠动画，其余浏览器保留原生展开。

[关键帧总览](transition-contact-sheet.png)、[采样记录](transition-final.json)与原始 JPG 保留。样式采样和截图编码不是原子操作；这些是实际浏览器的关键帧和完成态核对，**不是完整帧率录屏，也不能用于声称 60fps**。IAB 可见面板比逻辑视口窄，动效截图保留其实际裁剪，完整页面另见 previews。

[鼠标与手机检查](motion-and-mobile-checks.json)记录实际变换矩阵：桌面三层位移比例为 1:3:5，人物与阴影同父层；切至 390 后三层和轻风均为 none。暂停时三个深度层恢复 none。手机补充要求展开后滚到底部，页尾底部 712px，固定条顶部 763px，没有覆盖最后内容。

系统减少动态的 CSS 与 GSAP 媒体门禁已检查，IAB 未提供切换该系统偏好的接口，未做真实偏好切换。真实触控设备、软键盘、低端手机性能与网络限速仍需设备验收。旧 Figma 原生视频是设计参考，不替代本次网站检查。
