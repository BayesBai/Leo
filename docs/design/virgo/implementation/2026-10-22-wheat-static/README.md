## 本轮效果

封面的大号Virgo、标语、说明及CTA整体右移，1280以上左起16%，组宽min(620px,40vw)，右界不超56%；窄桌面平滑收回，手机24／20px边距不变。人物、导航、页脚与既有GSAP保持；故事标题精确改为`Virgo-拾穗`。

工作台复用无人花园背景，整屏固定晚霞麦田，贝壳色24%薄罩统一色温。主纸面80%，桌面仅装饰伪层8px模糊；手机纸面94%、无模糊。长文、编辑及输入94%，审核语义色、摘要、抽屉及固定操作保持稳定阅读底。模糊不施加在fixed操作祖先上，手机底条仍锚定视口。

本轮只改3个视觉源码文件，无新素材、无Figma写入。背景组件当前没有video，暂停／循环行为在静帧确认后的阶段实现。下阶段提示词见[视频制作说明](video-brief.md)。
