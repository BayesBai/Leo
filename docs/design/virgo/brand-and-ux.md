## 业务与原型边界

需求保留产品、客户／场景、1–4 渠道与补充要求，应用默认小红书；原型只覆盖有限双／四渠道模拟样例。方案摘要优先、按需编辑，保存后重新确认当前大纲；确认写作方向不等于审核通过。正文生成、独立审核、等待出图、排版与就绪分阶段，按实际 artifacts 展示来源、审核、渠道与版本。

受阻禁止复制、下载或正式出图；待确认保持警告，不随渠道或文案／视觉切换丢失。缺图返回调整渠道，不承诺上传。模拟产品不编参数、价格、优惠、评价或亲测，工具新色板不改变真实产品原图或渠道输出颜色。

API 基线 `2026-10-21-232930` 已有七天大纲／正文历史、30 分钟证据／成品期限和审核问题动作；本轮图稿不扩展历史页，不意味着程序没有这些能力，真实接口以[固定入口](../../api/README.md)为准。

## 动效与减少动态

封面原样：8 对画板、293 节点视觉属性比较无差异，交互目标仅重绑新版流程。原开场保留，不把原视频算成本轮重新制作。

本轮进入工作台为原生 600ms 全景淡出／纸面显现：场景保持原尺寸、0–350ms 淡出，纸面 200–600ms 显现，不再收束小窗。768 × 534／10fps 导出编码含终帧共 0.7s，0／0.3／0.6s 已抽帧，终帧与新需求页一致。减少动态入口 `87:21543` 的过渡 ≤100ms。

真实鼠标跟随未实现，没有循环视频背景素材；原生演示导出不等于网站代码。键盘焦点、触控、性能与真实 prefers-reduced-motion 仍须网站验收。
