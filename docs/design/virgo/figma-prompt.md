### A. 封面与过渡

封面 8 对画板、293 节点的视觉属性比较无差异，交互只重绑。600ms 进入工作台：场景保持全尺寸 0–350ms 淡出，纸面 200–600ms 显现，不再缩成小窗。原生导出 768 × 534／10fps、编码含终帧 0.7s；0／0.3／0.6s 抽帧终点为新版需求页。减少动态过渡 ≤100ms，无循环视频背景素材或真实鼠标跟随实现。

### B. 需求与营销方案

产品、客户／场景、1–4 渠道和补充要求保留，应用默认小红书，原型有限双／四渠道样例。未保存不得确认或生成，保存／AI 修改后重新确认当前大纲，确认方向不等于事实审核；自由输入、任意组合须在网站验收。

### C. 正文、审核与交付

保存修改 → 保存 v2 → 确认 v2 → 写作 → 审核 → 等待出图 → 排版 → 交付的目标链已读回。大纲版本与正文修订独立，失败／取消不冒充新结果。按实际 artifacts 展示渠道、来源、审核、标题与模板。

`blocked` 禁全部渠道复制／下载／正式出图，`needs_attention` 保留待确认项；成稿调整回方案流程。文案／视觉、图卡切换／放大和返回路径保留，工具色板不重染渠道成品。缺图返回调整渠道，不提供虚构上传入口。

缺图按钮为「返回调整渠道」，不承诺用户上传。没有先前结果时，不声称保留了上一份正文。取消、失败或断流不将旧稿伪装成新结果，也不自动切换模型模式或资料来源。

成功短文案：保存后提示「已保存为新版本，请重新确认」；确认后提示「本版大纲已确认，可以生成正文」；`passed` 提示「内容检查通过，发布前仍请人工复核」。
